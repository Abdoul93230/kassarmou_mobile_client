# 🎨 GUIDE : Créer le Graphique de Fonctionnalité 1024x500px

Le **graphique de fonctionnalité** (Feature Graphic) est la bannière promotionnelle affichée en haut de votre page Play Store. C'est **OBLIGATOIRE** pour publier votre app.

---

## 📐 SPÉCIFICATIONS TECHNIQUES

| Propriété | Valeur |
|-----------|--------|
| **Dimensions** | 1024 x 500 pixels (exactement) |
| **Format** | PNG ou JPEG (24-bit) |
| **Poids max** | 1 MB |
| **Ratio** | 2.048:1 |
| **Qualité** | Haute résolution |

⚠️ **IMPORTANT** : Le graphique doit fonctionner **sans texte** car Google peut superposer des éléments dessus.

---

## 🛠️ MÉTHODE 1 : Canva (RECOMMANDÉ - Facile et Gratuit)

### Étape 1 : Créer le Design
1. Aller sur https://www.canva.com/
2. Créer un compte gratuit (si besoin)
3. Cliquer sur **"Créer un design"**
4. Entrer les dimensions personnalisées : **1024 x 500 pixels**
5. Cliquer sur **"Créer un design"**

### Étape 2 : Designer la Bannière

**Éléments à inclure** :
```
┌────────────────────────────────────────────────┐
│                                                │
│  [LOGO]    KASSARMOU                          │
│            Marketplace Niger                   │
│                                                │
│  • Paiement sécurisé                          │
│  • Codes promo                                 │
│  • Livraison internationale                    │
│                                                │
└────────────────────────────────────────────────┘
```

**Conseils de design** :
- **Couleur de fond** : Utilisez `#30A08B` (vert de votre splash screen) ou dégradé
- **Logo** : Placez votre logo à gauche (vraisLogo.png)
- **Texte** : 
  - Titre : "KASSARMOU" en gros
  - Sous-titre : "Shopping au Niger"
  - 3-4 points clés avec icônes
- **Style** : Moderne, épuré, professionnel

**Palette de couleurs de votre app** :
- Primaire : `#E87E04` (Orange)
- Secondaire : `#008751` (Vert)
- Tertiaire : `#62aca2` (Teal)
- Fond splash : `#30A08B`

### Étape 3 : Ajouter des Éléments Visuels

**Éléments suggérés** :
- 📱 Icône de smartphone
- 🛒 Icône de panier
- 💳 Icône de carte bancaire
- 📦 Icône de colis
- ✨ Éléments décoratifs (formes géométriques)

**Dans Canva** :
1. Cliquer sur **"Éléments"** dans la barre latérale
2. Chercher "shopping", "mobile", "secure payment", etc.
3. Glisser-déposer sur votre design
4. Ajuster la taille et la position

### Étape 4 : Ajouter le Texte

1. Cliquer sur **"Texte"** dans la barre latérale
2. Choisir un modèle de titre
3. Écrire : **"KASSARMOU"**
4. Changer la police (recommandé : **Poppins Bold** ou **Montserrat Bold**)
5. Ajuster la taille (environ 60-80pt)

**Texte additionnel** :
```
✓ Paiement 100% sécurisé
✓ Codes promo exclusifs
✓ Livraison internationale
✓ Chat avec les vendeurs
```

### Étape 5 : Télécharger
1. Cliquer sur **"Partager"** en haut à droite
2. Choisir **"Télécharger"**
3. Format : **PNG** (recommandé)
4. Qualité : **Haute**
5. Cliquer sur **"Télécharger"**

## 🖌️ MÉTHODE 2 : Photoshop / GIMP

### Pour Photoshop
1. **Fichier → Nouveau**
2. Largeur : **1024 pixels**
3. Hauteur : **500 pixels**
4. Résolution : **72 ppi** (suffisant pour le web)
5. Mode couleur : **RVB**

### Pour GIMP (Gratuit)
1. Télécharger GIMP : https://www.gimp.org/
2. **Fichier → Nouvelle image**
3. Largeur : **1024 px**
4. Hauteur : **500 px**
5. Créer votre design
6. **Fichier → Exporter sous** → Choisir PNG

---

## 🎯 MÉTHODE 3 : Outils en Ligne Rapides

### Option A : Photopea (Photoshop en ligne gratuit)
1. Aller sur https://www.photopea.com/

2. Créer un compte gratuit

4. Designer votre bannière
5. Exporter en PNG

## 📱 MÉTHODE 4 : PowerPoint (Simple et Rapide)

1. Ouvrir PowerPoint
2. **Création → Taille de diapositive personnalisée**
3. Largeur : **26.67 cm** (1024px)
4. Hauteur : **13.02 cm** (500px)
5. Créer votre design avec :
   - Fond coloré
   - Votre logo
   - Texte "KASSARMOU"
   - Points clés avec puces
6. **Fichier → Enregistrer sous → PNG**
7. Qualité : Haute

## ✅ CHECKLIST AVANT D'UPLOADER

Avant de mettre votre graphique sur le Play Store, vérifiez :

- [ ] Dimensions exactes : **1024 x 500 pixels**
- [ ] Format : PNG ou JPEG
- [ ] Poids : < 1 MB
- [ ] Pas de texte trop petit (Google peut superposer des éléments)
- [ ] Logo visible et clair
- [ ] Couleurs cohérentes avec votre app
