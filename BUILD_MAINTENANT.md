# 🚀 COMMANDES RAPIDES - BUILD PRODUCTION

## ✅ Tout est vérifié et prêt !

### Lancer le build MAINTENANT :
```bash
cd kassarmou_mobile_client
eas build --profile production --platform android
```

### Voir le statut :
```bash
eas build:list
```

### Télécharger l'AAB :
Après le build, allez sur : https://expo.dev/accounts/[your-account]/builds

---

## 📋 Checklist Express

**Pendant le build (10-15 min)** :
- [ ] Prendre 4-8 screenshots de l'app (1080x1920)
- [ ] Créer graphique 1024x500 pixels
- [ ] Rédiger description courte (80 caractères)
- [ ] Rédiger description longue
- [ ] Créer politique de confidentialité

**Après le build** :
- [ ] Télécharger le fichier AAB (Android App Bundle)
- [ ] Créer l'app dans Play Console
- [ ] Uploader AAB + screenshots dans Play Console
- [ ] Soumettre pour révision

**Note** : Pour tester sur téléphone avant publication, build un APK séparé avec `--profile preview`
