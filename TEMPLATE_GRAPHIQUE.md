## 🎯 TEMPLATE CANVA - ÉTAPES DÉTAILLÉES

### Étape 1 : Fond
1. Créer design 1024 x 500 px
2. Ajouter rectangle pleine page
3. Appliquer dégradé :
   - Couleur 1 : #30A08B (coin haut gauche)
   - Couleur 2 : #E87E04 (coin bas droit)
4. Angle : 135°

### Étape 2 : Logo
1. Uploader votre fichier `vraisLogo.png`
2. Placer à gauche (X: 80px, Y: centré)
3. Taille : environ 150-180px de hauteur
4. Ajouter ombre portée légère (Opacity 30%)

### Étape 3 : Titre
1. Ajouter texte "KASSARMOU"
2. Position : À droite du logo (X: 280px)
3. Police : Poppins Bold ou Montserrat Bold
4. Taille : 80 pixels
5. Couleur : Blanc (#FFFFFF)
6. Effet : Ombre portée (X:2, Y:2, Blur:4, Opacity:40%)

### Étape 4 : Sous-titre
1. Ajouter texte "Marketplace Niger - Shopping Sécurisé"
2. Position : Sous le titre
3. Police : Poppins Regular
4. Taille : 30 pixels
5. Couleur : Blanc (#FFFFFF, opacity 90%)

### Étape 5 : Ligne de séparation (optionnel)
1. Ajouter ligne horizontale
2. Largeur : 400px
3. Épaisseur : 2px
4. Couleur : Blanc (#FFFFFF, opacity 50%)

### Étape 6 : Points clés
1. Créer 4 groupes icône + texte
2. Disposition en 2 colonnes x 2 lignes
3. Espacement : 40px entre chaque
4. Position : En bas du graphique

**Exemple pour chaque point** :
```
[Icône 💳]  Paiement Sécurisé
    ↓
Icône : 40x40 px
Texte : 22px, Poppins Regular, Blanc
```

### Étape 7 : Finitions
1. Ajouter formes décoratives en arrière-plan (opacity 10%)
2. Vérifier les marges (min 50px des bords)
3. Tester en miniature (zoom out)
4. Exporter en PNG Haute qualité

## 💡 ASTUCES PRO

### Pour un Résultat Plus Pro
1. **Utilisez une vraie photo de produit** (en arrière-plan, opacity 30%)
2. **Ajoutez un badge** "Nouveau" ou "Livraison Offerte"
3. **Incluez le drapeau du Niger** (petit, discret)
4. **Ajoutez un CTA subtil** : "Téléchargez maintenant !"

### Erreurs à Éviter
❌ Texte trop petit (< 16px)
❌ Trop d'informations
❌ Couleurs qui clash
❌ Image pixelisée
❌ Logo trop petit
❌ Texte difficile à lire

### Ce qui Fonctionne Bien
✅ Design épuré
✅ Couleurs contrastées
✅ Logo proéminent
✅ 3-4 points clés maximum
✅ Icônes reconnaissables
✅ Gradient subtil
