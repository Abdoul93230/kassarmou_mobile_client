## 🎨 PROMPT UNIVERSEL (ChatGPT, Claude, etc.)

### Version Complète - À Copier-Coller

```
Crée un graphique de fonctionnalité pour Google Play Store avec ces spécifications exactes :

DIMENSIONS :
- 1024 x 500 pixels (ratio 2.048:1)
- Format PNG haute qualité

CONTENU :
- À gauche : Mon logo Kassarmou (fourni en pièce jointe)
- Texte principal : "KASSARMOU" en très gros, police moderne et bold
- Sous-titre : "Marketplace Niger - Shopping Sécurisé"
- 4 points clés avec icônes minimalistes :
  • Paiement 100% Sécurisé
  • Codes Promo Exclusifs
  • Livraison Internationale
  • Support Client 24/7

PALETTE DE COULEURS (important) :
- Fond : Dégradé linéaire du vert #30A08B (gauche) vers l'orange #E87E04 (droite)
- Texte : Blanc #FFFFFF
- Accents : Orange #E87E04

STYLE :
- Design moderne et épuré
- Style e-commerce professionnel (inspiration Amazon, Jumia)
- Icônes minimalistes et ligne
- Ombres portées subtiles pour le relief
- Le logo doit être bien visible à gauche
- Marges de sécurité : 50px gauche/droite, 30px haut/bas

CONTRAINTES :
- Le texte doit être parfaitement lisible même en miniature
- Design équilibré, pas trop chargé
- Atmosphère chaleureuse et de confiance
- Évoque le shopping en ligne sécurisé

AMBIANCE :
- Professionnel mais accessible
- Moderne et technologique
- Inspiré des couleurs du drapeau du Niger (orange et vert)
- Sensation de confiance et sécurité

Ne mets pas de texte trop petit. Tout doit être lisible.
```

## 🔧 TROUBLESHOOTING

### Si l'IA ne génère pas les bonnes dimensions :

1. **Préciser dès le début** : "MUST be exactly 1024 pixels wide by 500 pixels tall"
2. **Utiliser ratio** : "aspect ratio 2.048:1"
3. **Redimensionner après** avec Photopea ou Canva

### Si le texte est illisible :

```
"Make all text much larger and bolder. 
The text must be readable at small size."
```

### Si le design est trop chargé :

```
"Simplify the design significantly. 
Remove all decorative elements. 
Keep only logo, title, subtitle, and 4 icons."
```

### Si les couleurs ne correspondent pas :

```
"Use exactly these hex colors for gradient background: 
left side #30A08B, right side #E87E04"
```

## 🚀 PROMPT MAGIQUE FINAL (LE MEILLEUR)

### À Utiliser avec ChatGPT-4 + Upload Logo

```
Crée un graphique de fonctionnalité professionnel pour Google Play Store.

📐 SPÉCIFICATIONS TECHNIQUES :
- Dimensions : 1024 pixels × 500 pixels (exactement)
- Format : Bannière horizontale 2:1
- Export : PNG haute qualité

🎨 DESIGN LAYOUT :
Position gauche (x:80px) :
  - Mon logo Kassarmou (je vais l'uploader)
  - Taille : ~160px de hauteur

Position centre-droite (x:280px) :
  - Texte principal : "KASSARMOU"
  - Police : Bold, moderne, sans-serif
  - Taille : Très gros (80px)
  - Couleur : Blanc pur #FFFFFF
  
Position en-dessous du titre :
  - Sous-titre : "Marketplace Niger - Shopping Sécurisé"
  - Taille : Moyenne (30px)
  - Couleur : Blanc #FFFFFF (légère opacité 90%)

Position bas (y:380px), 4 éléments en ligne :
  1. [Icône Shield] "Paiement Sécurisé"
  2. [Icône Tag] "Codes Promo"
  3. [Icône Box] "Livraison Int."
  4. [Icône Chat] "Support 24/7"
  - Icônes : Ligne blanche, style minimaliste, 40x40px
  - Texte : Blanc, 22px

🌈 PALETTE DE COULEURS :
- Fond : Dégradé linéaire
  • Point départ (0%) : #30A08B (Vert teal du Niger)
  • Point arrivée (100%) : #E87E04 (Orange du Niger)
  • Direction : De gauche à droite, angle 90°
- Tous les textes : #FFFFFF (Blanc pur)
- Icônes : Blanc, contour style "line art"

✨ STYLE VISUEL :
- Référence : Amazon, Jumia, marketplace professionnel
- Ambiance : Moderne, sécurisée, de confiance
- Design : Épuré, pas surchargé, respirant
- Typographie : Sans-serif moderne (style Poppins/Montserrat)
- Effets : Ombres portées légères (2px blur, 30% opacity)
- Marges de sécurité : 50px gauche/droite, 30px haut/bas

🎯 CONTRAINTES IMPORTANTES :
1. Le texte doit rester parfaitement lisible même en miniature
2. Design équilibré, hiérarchie visuelle claire
3. Pas de texte trop petit (minimum 20px)
4. Couleurs inspirées du drapeau du Niger
5. Évoque la confiance et la sécurité
6. Qualité graphique professionnelle

🚫 À ÉVITER :
- Design trop chargé ou cluttered
- Texte illisible ou pixelisé
- Couleurs qui clashent
- Éléments à moins de 30px des bords
- Plus de 4-5 éléments d'information

Génère cette image en haute qualité, prête pour le Google Play Store.
```

**Puis après génération** :
```
[Upload vraisLogo.png]
"Remplace le logo placeholder par mon logo uploadé"
```
